## Mechanics (PRD §14.1, exactly)
- `master.ts`: `CHAPTERS` (12 entries, durations from PRD §14.2, sum = 780 s — unit test), `evaluate(globalSeconds) → FrameState` PURE: `{chapter, localT, camera:{position,target,fov,roll}, sun:{dateKey, minutes}, grade, overlays:[...], routeReveal, feedCursor, hud:{...}, ...}`. Every chapter file: `(t ∈ [0,1], data: FilmData) → Partial<FrameState>`; blending between chapters for continuous camera moves/cross-grades ≥ 1.5 s handled in master. NO setTimeout/setInterval/Date.now in animation logic — a single rAF loop maps scroll/autoplay progress → `evaluate`. Determinism vitest: evaluate(t) twice → deep-equal; random t sweep monotonic chapter index.
- Tall scroll container + Lenis smooth scroll ↔ progress; autoplay (`Space`), speed `[`/`]` 0.85–1.15 step 0.05, `←/→` chapter jumps (1.2 s eased), `1`–`9`,`0`,`-`,`=` → chapters 1–12, `Esc` pause, `F` fullscreen, `T` tiny elapsed indicator (hidden by default), `H` hide chrome, `L` low quality, `A` → `/app` preserving city/date (and `/app` Backspace → film last chapter: add a tiny handler in a file you own, e.g. a `FilmReturnKey` component the /app page can mount — coordinate by adding it yourself to `(stage)/layout.tsx` if trivial). `?presenter=1` strip (chapter, elapsed vs target, next talking point from `docs/SPEAKER_NOTES.md` embedded at build — if notes don't exist yet, use the chapter's caption and leave a TODO line in OPEN_ITEMS). `?qa=1&t=<seconds>` jumps straight to a global time and sets `window.__zillFrameReady` after textures for that frame are loaded (for capture).
- `FilmData` loader: fetch once (behind the refined loading screen) `meta.json`, `hero.json` (`/api/scenarios/dubai_downtown`), shade index for `summer` + `hackathon`, recorded agent sessions (`/api/agent/replays` + the session JSON; if the endpoint isn't there, read the files list from `/api/cities/...` is NOT possible — then ask in report and use a static import copied into `frontend/src/film/data/` at build by a small script `scripts/sync-film-data.mjs` you own), `data/test_results.json` (via a static copy made by the same sync script). EVERY number on screen comes from these. Missing value → render the `[TEAM TO FILL — cite source]` tag style, never a made-up number.
- Badges, truthfully: agent feed "Recorded session" if replay file `live:true`, otherwise "Scripted session — live model not connected"; build log "Cached build"; weather "Representative profile" when `synthetic_representative`; fleet "Simulated"; policy "verify".
