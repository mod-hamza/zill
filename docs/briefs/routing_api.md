3. `routing/tdsp.py`: time-dependent A* per PRD §8.1–8.2 exactly (cost = travel time + travel time·λ·w_m·sun_e(τ)·uv(τ)·comfort·crowd ; penalty separate from time; arrival-time lookup with linear interpolation between 10-min steps; crossing wait; stairs factor/forbidden; mode masks). Heuristic = euclid/speed (admissible because cost ≥ time). Return per-vertex arrival times and CONTRACTS §5 RouteResult incl. segments + WGS84 latlon. `compare(ctx, o, d, mode, depart, date_key, lambdas=(0,1,3))` returns fastest/balanced/coolest with relative stats. Performance: < 300 ms per route on the real graph (measure p50/p95 over 50 random pairs; vectorise sun lookups — precompute per-edge exposure at the step pair once per query window).
   Honesty rule for invariants: if the λ=3 path ends up with MORE sun_exposure_s than fastest (possible with time-dependence), choose the lower-RHL of {coolest, balanced, fastest} as "coolest" and set `stats.note`. Log in DECISIONS.
