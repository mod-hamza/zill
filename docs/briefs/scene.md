## Build (quality first — this is the visual heart of the pitch)
1. `state/`: zustand stores `useCity` (meta, loaded assets, progress), `useSun` (date_key, minutes-of-day, derived alt/az via `lib/sun.ts`), `useRoute` (A/B, mode, λ, results, view: analysis|presentation), `useStage` (mode: film|app, quality tier, debug).
2. `lib/sun.ts` with suncalc: alt/az (az clockwise from north — convert from suncalc's south-based azimuth carefully), sun direction vector per CONTRACTS (x=sin az·cos alt, y=sin alt, z=−cos az·cos alt). Vitest vs `data/curated/sun_golden.json` (copy into `frontend/src/lib/__fixtures__/` at test time or import via relative path) within 0.5°. Vitest for geo vs `data/curated/geo_golden.json`.
3. `three/Scene.tsx` (Canvas, ACES or AgX tone mapping, sRGB, shadows on, dpr by tier), `CityBuildings.tsx` (useGLTF, one material: matte warm stone roughness 0.85, onBeforeCompile or custom shader for: per-building ±4% lightness from `_BUILDING_ID` hash (warm hues only), roofs slightly lighter (normal.y), very-low-contrast vertical window lines, dusk tungsten windows on ~35% floors by hash driven by a `dusk` uniform, ground-contact AO darkening in the first ~6 m), `ShadeGround.tsx` (ground plane in the core grid extents, two textures of adjacent steps blended by time fraction, colour map sun_fraction → `shade #22333A` (high opacity) … `sand`-tinted sunlit ground per PRD §13.1.3 via OKLab-ish ramp, soft edges, prefetch ±3 steps, fade-in no pop, UV computed from world x/z per CONTRACTS §2), roads/paths as faint lighter ribbons from graph.json (merged into one BufferGeometry), parks muted, `Sky.tsx` (Rayleigh-ish gradient by sun altitude, soft sun disc at true az/alt, horizon haze, dawn/noon/golden/dusk grading uniforms), `SunLight` (DirectionalLight, shadow camera fitted to a ~600 m box around the camera focus, 4096 map on high tier, PCF soft), `Trees.tsx` (instanced low-poly canopies, muted sage/olive), `Links.tsx` (covered/AC links as thin oasis ribbons with faint inner warm glow), `Routes.tsx` (tube/ribbon 1 m wide at +0.15 m, analysis view = per-vertex exposure ramp shade→#6F6A55→ember, presentation view fastest=slate / coolest=brass with a slow travelling soft pulse driven by a `t` prop, traveller marker), `post/` (EffectComposer: very subtle bloom (high threshold), SSAO low (high tier only), vignette 0.25, film grain ≤ 0.06 deterministic by frame-t, custom grade pass by time-of-day; quality tiers high/medium/low; `?q=low` forces low), `rigs/` pure functions `(t, params) → {position, target, fov, roll}`: OrbitRig, DollyRig, CraneRig, FlyRig (CatmullRom path, lookahead, bank ≤ 4°, eased speed), TimeRig + deterministic seeded "float". A `CameraDriver` component that applies a rig state each frame from the store (no internal timers — the Film will drive `t`).
   Performance: ≤ 400 draw calls, 60 fps target on the RTX 4070; auto-downgrade DPR/effects if frame time > 22 ms for 2 s; `?debug` shows FPS/draw calls. WebGL context-loss handler. Refined loading screen ("Preparing Downtown Dubai…" with a thin brass progress line).
