- 2026-10-22 shade: polygon rasterisation via own numba even-odd scanline at cell centres (no skimage/rasterio dep) — holes handled for free, deterministic.
- 2026-10-22 shade: soft edges = 5 sun-disc samples (centre + 4 rim, 0.265 deg) with sun-aligned ±0.35-cell ray-origin offsets (anti-aliasing); no blur — keeps 90° rotation equivariance exact (tested).
- 2026-10-22 shade: raymarch accelerated with 2-level max-filtered height grids (skip 6/40 cells when the ray is above everything nearby); exact, keeps O(N·steps) raymarch instead of the sweep fallback — synthetic 1300² grid 0.3–0.54 s/step on 24 cores.
- 2026-10-22 shade: tree canopy attenuates once per distinct tree crossed (tree-id grid), canopy bottom = 0.35·h; ray-vs-canopy tested as a height interval per step so a pedestrian directly under a tree at noon is shaded.
- 2026-10-22 shade: buildings with min_height > 1.5 m (bridges/floating parts) block rays in [Hmin, Hmax] but are not in building_mask (ground below is walkable).
- 2026-10-22 shade: sun_golden.json `alt` = geometric elevation (suncalc has no refraction); engine uses pvlib apparent elevation; `alt_apparent` stored too.
- 2026-10-22 shade: exposure samples whose cell is inside a footprint and >3 m from outdoor keep the raster value 0 (path runs under a building mass) — counts logged in shade/bake_log.json.
- 2026-10-22 agent: replan delta-arrival is measured against the *disrupted baseline* (committed arrival + delay for a delay; committed arrival for closure/heat) — for a fixed path the duration is clock-independent (constant speed), so a bare 20-min delay would otherwise always exceed the L3 10-min limit and nothing could ever auto-apply; RHL limit (+10%) is vs the committed plan as planned (baseline RHL of the old path at the later time is not re-evaluated). Both deltas are in the `replan` event (`delta_arrival_s`, `delta_arrival_vs_committed_s`).
- 2026-10-22 agent: Planner replies with JSON `{plan_id, recommendation, text}`; Verifier = deterministic layer (tokens, bare numbers, edge validity for mode, arrival window, policy pack, qualitative claims vs stats) + separate LLM call (live only; scripted sessions skip the LLM layer and say `layers:["deterministic"]` rather than rubber-stamping).
- 2026-10-22 agent: numeric guard is strict: any digit (incl. Unicode digits, fractions) or spelled-out cardinal (two..ninety, hundred, half, dozen, "one minute") not present in the user's own message is rejected; ordinals and line-start list numbers are allowed. Fallbacks: narrator retry -> verified draft -> deterministic template -> sentence redaction.
- 2026-10-22 agent: token units are printed by the resolver (`_min` "4.5 min", `_pct` "62%", `_time` "13:45", `_m` "820 m", `_km`, `_s`, `_c`); `_pct` fields are assumed to be 0-100 (as in CONTRACTS 5 naming), derived `X_min` from `X_s`, `X_km` from `X_m`, `X_time` from ISO `X`.
- 2026-10-22 agent: scripted planner (no API key tonight) issues real tool calls and branches on their results (departure optimiser if flexible, policy check -> compliant re-plan for crew); sessions are recorded with `live:false`, with scripted minimum pacing (`"pacing":"scripted-minimum"`); `scripts/record_replay.py --live` re-records with the real model.
- 2026-10-22 agent: `UAE_OUTDOOR_WORK` pack lives in `data/curated/policy_packs/uae_outdoor_work.json` (`verified:false`); crew work blocks at a site are conservatively assumed sunny (`assumed_sun`) because site exposure is unknown.
- 2026-10-22 agent: recordings add a `phase` ("plan"|"approve"|"monitor") to each item so the UI can step message -> approve -> simulate through one recorded session; replayed events carry `payload.replay = {source: recorded|scripted, label, scenario_id, phase}`.
- 2026-10-22 routing: traversal time includes crowd x1.15 on indoor/ac_link (real slow-down, PRD 6.6) while `comfort` scales only the sun penalty (PRD 8.1); exposure applies to `open` edges only, so indoor/covered edges are sun-free regardless of table values.
- 2026-10-22 routing: crossing wait (8 s walk / 10 s cycle, scooter) is added when LEAVING a crossing node that is not the origin (once per pass); the wait counts as time at that edge's sun state.
- 2026-10-22 routing: sun_e is looked up at the clock time the traveller reaches the edge's start node (arrival-time lookup, linear interpolation between 10-min steps); time-of-day only, the table's date is `date_key`.
- 2026-10-22 routing: honesty rule — "coolest" = lowest-RHL route among {lam=3, lam=1, fastest} whose sun_exposure_s <= fastest's; when lam=3 is not that route (time-dependence), `stats.note` says so.
- 2026-10-22 routing: `route()` fills relative stats (added_time/sun_saved/rhl_saved) against a cached lam=0 baseline so callers that route one lambda at a time (agent backend) still get CONTRACTS 5 stats; `compare()` is the canonical triple. `route(..., blocked_edges=)` supports closures for replanning.
- 2026-10-22 api: added `api/common.py` (orjson response, request-id middleware, typed error handlers) and one `common.install(app)` line + routers in `api/main.py`; `/api/health` in main.py now delegates to `routes_misc.health_payload()`.
- 2026-10-22 api: `ctx.exposure(date)` raises ShadeUnavailable (HTTP 409 shade_unavailable) for non-baked dates instead of silently computing for minutes; clients call POST /api/shade/compute first.
